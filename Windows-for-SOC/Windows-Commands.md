~ Windows Commands for SOC Analysts

This file contains Windows commands that are useful for SOC analysts.

1. System Information

a. systeminfo

Displays detailed information about the Windows system.


b. hostname

Displays the computer name.

2. User Information

a. whoami

Shows the currently logged-in user.

b. whoami /all

Displays detailed information about the current user's privileges and groups.

3. Network Information

a. ipconfig

Displays IP configuration information.

b. ipconfig /all

Displays detailed network configuration.

c. netstat -ano

Displays active network connections and associated process IDs.

4. Process Information

a. tasklist

Displays currently running processes.

5. SOC Relevance

These commands can help a SOC analyst:

Identify the current user
Gather system information
Investigate network connections
Identify running processes
Investigate suspicious activity
